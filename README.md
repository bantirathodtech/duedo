# 🚀 Duedo: Debt Tracker & Planner (Ironman Grade)

**Take control of your financial freedom.** Duedo is a premium, high-performance financial tool designed to help you track debts, plan growth, and visualize your journey to a debt-free life.

---

## 💎 Features

* **⚡ Ironman Grade Performance**: Optimized with a staggered, deferred initialization sequence for ultra-fast perceived startup speed.
* **🛡️ 100% Stable Test Suite**: Verified with 95/95 passing unit and widget tests, ensuring reliability in production.
* **📺 Premium Ad-Gate**: Smart monetization system with 30s rewarded ads for free users and seamless PRO upgrades.
* **Financial Freedom Dashboard**: A high-fidelity overview of your total debt and payoff progress.
* **AI Predictor**: Smart algorithms that compute your estimated "Freedom Date" based on current repayment behavior.
* **Cloud Synchronization**: Secure, anonymous cloud backup powered by Supabase with robust offline fallback.
* **Premium Edge UI**: A stunning, responsive dark-mode interface with glassmorphism, dynamic animations, and integrated haptics.

---

## 🛠️ Tech Stack

* **Framework**: [Flutter](https://flutter.dev) (v3.10+)
* **State Management**: Riverpod (for reactive, testable architecture)
* **Backend**: [Supabase](https://supabase.com) (Anonymous Auth, Cloud Sync, RLS)
* **Local Database**: [Drift](https://drift.simonbinder.eu) (SQLite for persistent local-first storage)
* **Ad Engine**: Google Mobile Ads (AdMob) with App Open & Interstitial support.

## 🏁 Getting Started

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/bantirathodtech/duedo.git
   cd duedo
   ```

2. **Install dependencies**:
   ```bash
   flutter pub get
   ```

3. **Run the app**:
   ```bash
   flutter run
   ```
